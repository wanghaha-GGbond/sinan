# 在场 Web 前端 PRD · V1.0 RC1

日期：2026-10-26（Asia/Shanghai）。状态：首个前端基线候选，尚未正式合并或上线。

设计来源包括 g2561845325-debug 的 [PR #4](https://github.com/wanghaha-GGbond/sinan/pull/4)，采用选择性移植，不整包合并。取舍记录见 [UI/UX 基线](../../uiux-v1-baseline.md)，执行证据见 [验收记录](validation.md)。

## 1. 产品目标和范围

在场帮助用户查找公司、阅读匿名评价与研究资料，并贡献经审核的工作体验。
本版固定“找公司 → 看公司 → 看评价 / 写评价”的主路径，减少无效控件，不扩展业务。

- 改版页面：首页 `/`、目录 `/companies`、概览 `/company/[id]`。
- 共享组件影响：搜索结果中的公司行、评价列表、导航及搜索输入，需要一起回归。
- 保持兼容：研究、注册登录、账号找回、评价提交与审核、有用投票、账号注销。
- 不纳入：iOS 改版/发布、正式 Pulse、社区、私聊、拍卖、公司资料扩充 #5、另一套视觉 #6、评分算法变更。
- 保留绿色动作色、现有主题变量与字体，不整体替换全局 CSS。

## 2. 用户权限

| 用户 | 核心能力 | 保持的限制 |
| --- | --- | --- |
| 访客 | 查公司、研究、公开评价；登录注册入口 | 不绕过登录/邀请要求，不展示私密身份 |
| 登录用户 | 写评价、有用投票、账号管理 | 以真实 API 授权和审核结果为准，不假成功 |
| 审核人员 | 原有审核页面和操作 | 本版不修改权限或审核逻辑 |

## 3. 三页规格

### 首页

- 唯一主搜索框：公司名称，Enter/搜索进入 `/search?q=…`；空输入进入空搜索页。
- 提供全部公司、公司研究入口。
- “公司速览”显示原 API 顺序的前 6 家，不宣称个性化推荐，也不重新定义排序算法。
- 公司行展示名称、行业、城市、规模（有则显示）、简介/亮点、评分与评价数；整行是可访问链接。
- 保留查询缓存和请求去重；加载用骨架，失败可重试，不以演示数据替代失败。

### 公司目录

- 顶部集中搜索、城市选择、排序，结果单列展示。
- 保留评价最多、评分最高、推荐率最高三个排序，不放没有回调的搜索按钮。
- 搜索实时过滤当前已加载目录；无匹配提供清除筛选，清空关键词和城市，保留排序。
- 接口目前最多返回 50 家；本地筛选不等于全量搜索，服务端分页不在本版范围。
- 继续使用原 API、请求键、缓存时长和公司审核规则。

### 公司概览

- 顶部展示公司名、行业、城市、规模、已有认证状态、真实方向评分和评价数；主要操作写评价。
- 公司初始字为占位，不伪装官方 Logo；长名称允许换行。
- 导航保留概览/评价/评分/承诺；概览正确设置 `aria-current=page`。
- 评价主栏、统计次栏，手机纵向排列；保留部门洞察、承诺记录、情绪趋势。
- 待审核公司继续阻断评价；不存在为 404，读取失败显示错误，不兜底成功。
- 删除无行为的关注公司；薪酬有样本显示“公开薪酬”，不推断“中上”。
- 评价分类用一个真实下拉框，仅有主题标签时显示主题筛选；移除无行为的职位/年限等控件。
- 有用、补充经历、举报等沿用原组件与后端调用，不改变审核或隐私边界。

## 4. 数据口径

- 方向评分保留 API 的 0–10 标度，不除以二、不新增星级换算。
- 有评价且评分为 0–10 有限数才显示；无样本、缺值、NaN、越界值显示暂无评分；有效的 0 分保留。
- 分布显示原始区间和数量，不能把 `8-10` 误标为 5 星；没有样本不造分布或推荐率。
- 评价数、公司规模、已验证人数是不同指标，不混用。
- 归档截图来自隔离的本地 fixture，不代表真实雇主表现或线上用户数据。

## 5. 交互与视觉约束

- 首页、目录、搜索已有输入框时隐藏导航重复搜索；其他页面保留。
- 手机与桌面访客都显示文字登录，删除无行为通知与假红点。
- 公司行支持 Tab/Enter、可见焦点，不嵌套按钮。
- 调整后的控件触控区域至少 44px；骨架尊重减少动画偏好。
- 验收宽度：375、390、768、1280、1440px；长英文名称不造成横向滚动。
- 使用短标签，但保留隐私法律说明、审核限制和必要错误反馈。

## 6. 可复用组件与修改方式

| 组件 | 责任 | 可修改边界 |
| --- | --- | --- |
| CompanyCard | 首页、目录、搜索公司行 | 布局/密度可调，链接和数据口径不变 |
| CompanyRating | 评分、无样本表现 | 字号可调，不私改标度 |
| CompanyListSkeleton | 加载占位 | 行形状与数量，不引入业务数据 |
| CompanyDirectory | 搜索、筛选、排序 | 控件排列可调，已有能力保留 |
| CompanyEvidenceRail | 统计信息 | 视觉层级可调，不造样本 |
| WebNav / SolidSearchInput | 导航、搜索 | 变更要回归所有调用页面 |

第一版不新增在线设计编辑器依赖。后续可建立 Figma 对应组件与 Storybook 样例；设计稿、真实代码和验收截图分别管理。设计调整经 PR、Preview 和另一人验收，不直接发布生产。

## 7. 业务与发布安全

- UI 增量不修改 API、数据库、认证、审核与授权代码。
- 整合分支包含 PR #1 尚未合入的 33 个 release 提交，因此整份 PR 不是纯 UI；其中有 `0021` 和会话兼容要求。
- 线上参考 Worker：`ea4117e2-094a-495f-9ab7-3694e006a6cb`，注释 `copy-cleanup-f318506`。它不是已验证的新认证回滚目标。
- 发布前备份、验证迁移和 `session_version`；不执行数据库向下迁移。
- 合并不等于部署。检查、隔离 Preview、另一人批准不足时不合并或切生产流量。
- 不降低分支保护、不关闭审计，不用本地构建冒充已部署 Preview。
