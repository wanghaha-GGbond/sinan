## 保留和调整

| 页面 | 合入的视觉 | 保留的业务 |
| --- | --- | --- |
| 首页 | 绿色公司标识、卡片信息层级、查看公司入口 | 搜索、公司研究、共享查询缓存；不恢复营销说明文案 |

## 验收和追踪

- 本机：页面回归（含注册、个人主页、慢请求缓存、375–1440px、深色模式）、社区隔离预览、96 项业务单测、lint、typecheck、生产 build。
- 深色模式评分和注册按钮文字对比度要求至少 4.5:1。
- GitHub：PR #7 当前 HEAD 的 Web/iOS、PostgreSQL 全量迁移和核心流程、Vercel 独立 Preview、Cloudflare 构建检查全部通过后才能合并。
- UI 截图由 GitHub `Web UIUX V1 regression` 的 artifact 保存；本机在 `apps/web/test-results/uiux-v1` 和 `community-ui`，均不包含真实用户数据。
- 仓库所有者本次明确要求不再等待朋友批准。若仍被审批数阻挡，仅对这次合并临时调整审批数，保留必需 CI 和其他规则，操作后立即恢复 1 个批准。不得伪造他人批准。
- GitHub 合并不等于 Cloudflare 正式站点已更新；发布状态和 SHA 以部署记录为准。免费测试邮件的收件限制及自有发信域名要求不因 UI 合并而改变。

## 2026-10-31 补充调整

- 目录加载占位与双列/单列卡片保持一致；短页面页脚贴底。
- 首发范围内隐藏实际不可访问的“评分”分区，保留评价和研究入口。
- 增加键盘跳过导航入口和页脚帮助入口；支持页的账号入口可点击。
- 删除未配置时的旧域名支持邮箱及未经确认的处理时限，不假装已有可用联系地址。
- 页面回归改为正式构建，30 项全部通过，包括注册失败提示、禁用发信、个人主页和慢请求行为。此处的注册测试使用隔离拦截，不代表正式邮件投递完成。
