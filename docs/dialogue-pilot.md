# 在场 · 对话：免费报名试点

## 本版边界

社区内的工作经验交流，不是独立交易市场。嘉宾资料、活动介绍、报名提问、管理员筛选、私密参与安排、撤回报名与授权后的公开纪要构成第一版。

**没有竞价、收款、捐赠、嘉宾结算或退款功能。** API 固定返回 `paymentsEnabled=false`、`biddingEnabled=false`、`donationStatus=not_started`，严格拒绝金额、收款账户、捐赠凭证和调用者身份等额外字段。不预置虚构嘉宾、活动或公益成果。

`fundingMode` 仅是筹备意向：`undecided`、`all_donated`、`host_and_donation`，不代表已经捐赠，也不承诺全额捐赠。当前运营主体、司法辖区、资金分配与合作机构尚待所有者确认。历史拍卖设计中的“全额捐赠即无合规问题”不能作为上线依据，原拍卖页面/API 继续受既有公开范围限制。

## 页面与责任

- `/community/dialogues`：公开活动列表，支持公司过滤和分页。
- `/community/dialogues/[id]`：嘉宾、时间、介绍、免费报名。
- `/me/dialogues`：仅本人可见的问题、结果、入选后的参与安排与撤回。
- `/moderation/dialogues`：仅当前有效管理员/审核员可操作。管理权限在页面和每个 API 中重新检查，不信任客户端角色或请求中的用户 ID。

社区和公司页提供次级入口，“我的”提供报名入口。主导航仍仅为“社区 / 我的”。没有自动邮件通知；管理员通过参与安排告知入选者，报名者在“我的报名”查看。

## 活动流程

1. 管理员核对真实嘉宾及授权后保存草稿；未确认授权不能发布。此版草稿不支持修改，需取消并重新创建。
2. 发布后开放免费报名。报名截止早于开始时间；报名者仅提交一个私密问题，不购买席位、不保证入选。
3. 审核员筛选并填写报名者可见的处理说明。所有筛选和撤回共享活动行锁，不能超出名额；旧状态的重复操作返回冲突。
4. 私密参与安排仅向本场已入选者展示，普通报名者、其他用户和公开 API 均不可获取。管理者不得填写收款链接或要求转账。
5. 结束报名后，实际活动结束才能标记完成。公开纪要必须取得嘉宾及相关参与者授权；不会自动公开报名问题。
6. 取消公开活动会展示原因并移除参与安排。隐藏活动返回 404，并移除本人页面的参与安排。未公开草稿即便取消也不会进入公开列表。

谈论合法的工作经历，不买卖商业秘密、个人隐私、未公开敏感资料或违法内容。嘉宾授权和纪要授权由运营人员人工核实，勾选框不是平台自动认证，也不替代实际授权记录。

## 数据与安全

新增迁移：`0026_dialogue_pilot`。活动、报名、操作审计分表保存；只向公开页面投影必要字段，不返回报名者 ID、邮箱、请求标识或私密安排。所有接口禁止缓存；私密查询按用户隔离，卸载后不保留缓存。写操作继承本站来源校验、16 KiB 请求体上限和用户/IP 限流。

保存和报名使用请求标识防止重试重复创建；失败不显示成功、不清空表单。撤回需再次确认，并清除问题、处理说明和名额占用。账号注销删除个人报名并解除活动创建者/审计操作者的关联。审计不复制报名原文和参与安排；处理说明是受限操作记录。

## 发布开关与验收

`NEXT_PUBLIC_DIALOGUE_ENABLED` 必须在构建时及运行时均明确为 `true` 才启用；默认关闭。请求代理与 API 额外动态读取运行时变量，避免只看已编译的公开开关。运行时关闭会使所有新页面/API 返回 404，不访问数据库；已发给浏览器的导航入口需要下一次关闭开关的构建才能消失。当前 Cloudflare 正式发布配置没有开启本模块。

受保护的 Vercel Preview/staging 配置启用试点，并仅使用隔离测试数据库。不能只更改正式站开关：应先审批发布，备份，再应用全部当前迁移，验证 readiness、注销兼容性及实际报名流程，最后发布同一提交的构建。迁移无 down 操作；应用回退不能撤销数据库变更。正式环境未执行本版迁移、未创建活动、未开启资金交易。

验收覆盖：输入及开关、未授权/跨站写入、无数据库失败关闭、公开/私密隔离、幂等重试、并发名额、状态冲突、撤回清除、分页、截止时间、纪要授权、账号注销；浏览器覆盖真实隔离数据库全流程，以及 320/390/1280 宽度与明暗主题。先运行 `test:uiux` 生成开启模块的构建，再运行 `test:dialogue-gate` 验证同一构建在运行时关闭后所有新入口返回 404。模拟页面测试不等于真实数据库或正式站验收。

## 真实拍卖的后续门槛

另开项目确认运营主体与地区、嘉宾身份和合同、公益合作方及授权、报酬/捐赠/费用分配、持款路径、支付机构准入、取消退款、履约争议、税务和真实凭证披露。未经明确批准，不开放竞拍、资金入口或自动转账，不以“公益”替代这些要求。
