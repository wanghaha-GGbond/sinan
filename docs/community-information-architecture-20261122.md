# 在场：公司属于社区（PR36 最终结构）

本轮替代 11 月 21 日的三项导航方案。公司是社区内的空间，不再是并列的顶级模块。

## 入口与内容

- 主导航：社区、我的。手机底栏同样两项。
- `/` 与 `/community` 展示同一个社区入口，默认聊工作；不重定向注册或要求登录浏览公开内容。
- 社区板块：聊工作、公司评价、找公司。
- `/community?view=companies` 承接原首页的公司搜索、推荐/最新、Logo 和新收录公司。按需加载，不让讨论首页预先加载公司发现界面。
- `/companies` 保留现有目录与城市/排序/评价筛选链接，也使用社区外框与板块导航。旧书签、搜索链接和公司地址不变。
- 公司主页面包屑返回社区；公司概览、讨论、评价、多维评分、问卷、C-BTI 与承诺记录原有功能和 API 均保留。
- 公司内只保留原公司信息导航，不叠加一套全站社区板块切换。
- 工作记录继续折叠在「我的」；公开研究页面/API 仍关闭，研究数据库与算法保留。

## 切换边界

- 聊工作/评价沿用现有链接、公司上下文与历史记录。
- 进入找公司不携带帖子筛选参数；目录返回讨论也不把城市/评分排序误发给帖子 API。
- 后退、刷新和直接打开链接均应呈现当前板块。公司推荐与目录共享现有查询缓存。
- 发现公司时不请求帖子流；帖子接口返回异常格式时显示重试，不将异常伪装成空社区。
- 请求时渲染社区板块 HTML，保留慢网、脚本未就绪时的链接语义和推荐切换禁用反馈；不在服务端读取用户数据库。

## 发布范围

沿用 PR36。不删功能、迁移或生产数据；不改账号权限、密钥和环境保护。当前提交仍需 CI、受保护的隔离 staging 和正式发布验收，提交 PR 不代表已上线。
