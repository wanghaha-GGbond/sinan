# Web UI 整理：我的空间（2026-11-16）

本轮是全站 UI 改进的第一批，不是“所有页面已经定稿”。正式站是否更新，以合并、发布和线上版本验收记录为准。

## 信息架构

- 桌面主导航：公司、社区、写评价、我的。
- 手机底部：公司、社区、评分、我的。移除重复的顶部折叠菜单。
- 我的空间：概览、打卡与周报、公司研究。
- `/pulse`、`/research`、`/research/[slug]` 原网址保留，不改 API，不迁移用户数据。
- 研究仍然公开；“放进我的”是入口分组，不是新增登录限制。
- 游客也能在我的页找到工具；个人记录仍需登录。登录后返回原打卡入口。
- 公司论坛高亮社区；公司评分等页面高亮公司；研究和打卡高亮我的。

## 公共 UI

- 全局深浅色切换、明确的当前页标识、键盘焦点。
- 手机底栏收敛到四项，保留安全区；320px 窄屏保留 Z 品牌标识。
- 个人页工具卡、社区入口、资料操作排布整理。
- 评价讨论输入框、举报选项、筛选栏和个人收藏 hover 改用主题色，不再硬编码白底。
- 研究、周报和个人页使用一致的内容宽度。

## 不变的业务边界

- Pulse 开关与公司匿名统计人数阈值不变；不生成假周报或示例评分。
- 公司评分、论坛、邮件注册、研究算法与 API 不变。
- 不包含图片上传，不开通新的付费服务，不修改生产数据库。

## 验收与后续

本轮测试覆盖导航映射和开关、游客/登录态、320/390/768/1280px、深浅色、研究与打卡往返、主题持久化，以及既有全站页面回归。

本地最终结果：128 项单测、123 项生产构建下的页面回归通过；typecheck 通过，lint 0 错误（保留个人公开页的 2 条既有警告）。已查看桌面浅色、手机深色与登录后个人页截图。测试 API 为隔离页面 fixture，不宣称已完成新一轮真实 staging 数据库验收。

后续按页面继续细化公司详情与评分步骤、帖子详情与讨论、个人页次要信息密度；不能用主导航整理替代这些页面的完整验收。

## 独立依赖风险

复验构建触发 Next.js 的安全提醒。独立 `npm audit --omit=dev` 确认 high/critical 均为 0，但包含 `next@16.4.3` 的中危 GHSA-mfr8-8qww-v76h，仍建议单独提交安全补丁并验证 OpenNext 兼容性。本轮未改依赖或锁文件，也未运行构建日志建议的自动升级命令。

官方公告：https://github.com/vercel/next.js/security/advisories/GHSA-mfr8-8qww-v76h 。应用源码与 Next 配置未搜索到该公告描述的 `use cache` / `unstable_cache` 组合；这不等同于依赖风险已修复。
