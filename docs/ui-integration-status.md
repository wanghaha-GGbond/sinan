## 本轮 UI 增量

在现有目录中合入 PR5 的“只看有评价”和“最近收录”，保留原有推荐率排序、加载/失败/清空状态及响应式双列。按真实样本判断评分排序；无样本的历史分数不能被排到已评价公司前面。补齐英文名/别名搜索和确定性排序；不改后端评分定义。
