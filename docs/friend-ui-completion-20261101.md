## 不伪装成已完成的部分

- PR3 的 Pulse 演示原型继续受现有开关保护；生产仍不开放模拟打卡、虚构员工周报或公司趋势。真实打卡、周报和 30 人聚合阈值仍需独立实现，不能把这项写成“已完成”。
- PR5 的公司资料扩充和旧 seed 不随本次 UI 工作自动写入生产。本次公司介绍与官网来自已审核数据库；没有官网的公司不凭空生成“来源”。
- 原稿的演示评价、五分制、未实现的通知按钮不引入生产；原稿解释性营销文案仍按所有者此前要求省略。
- Figma 保持暂缓，未将截图称为可编辑设计稿。

发布需适用 CI、隔离 Preview、数据库集成、Cloudflare 实际运行及线上验收通过；后续记录准确的 source SHA、main merge、平台 version 和 release，而不只记录 PR 已合并。
