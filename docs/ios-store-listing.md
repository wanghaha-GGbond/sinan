# 在场 iOS 商店素材与 TestFlight 文案

## 产品信息

- 名称：在场
- 副标题：入职前，先看清方向
- 类别建议：商务（主）/ 社交（次）
- Beta 描述：在场是一款面向职场人的公司信息与匿名评价工具。测试版支持邀请注册、公司搜索与详情、匿名评价与评分、公司研报，以及评价审核。
- App 图标：`apps/ios/assets/icon-v2.png`（1024×1024、RGB、无透明通道、无预制圆角）。
- 测试重点：邀请注册、登录态跨重启、公司搜索、公司详情、提交匿名评价、研报阅读、账号注销与数据删除。
- 不在首发范围：拍卖、圈层、私聊等实验功能不会出现在主导航。

反馈邮箱使用 `SUPPORT_EMAIL`，隐私政策 URL 使用 `${NEXT_PUBLIC_APP_URL}/legal/privacy`，支持 URL 使用 `${NEXT_PUBLIC_APP_URL}/settings/account`。这些值及审核邀请码必须使用真实生产信息，不得提交占位内容。

## 截图清单

每套截图使用同一组已审核的演示数据，不出现真实用户邮箱、邀请码、JWT、内部审核备注或未公开评价。

1. 首页：真实公司推荐与“入职前，先看清方向”定位。
2. 搜索：公司搜索结果。
3. 公司详情：评分、评价摘要与研报入口。
4. 匿名评价：维度评分和匿名说明，避免输入真实个人信息。
5. 研报列表：突出资料来源和更新时间。
6. 研报详情：展示结论、证据和风险提示。

至少准备 6.7 英寸 iPhone 截图；如 App Store Connect 要求，再补 6.5 英寸兼容套图。截图必须来自 Release/production API 构建，不使用设计稿冒充运行画面。

## App Privacy 填报基线

- 联系信息：注册邮箱（用于账户与认证，不用于追踪）。
- 用户内容：评价正文、评分及用户主动提交的内容。
- 标识符：内部账户 ID。
- 诊断：只有生产错误追踪实际启用时才勾选崩溃或性能数据。
- Tracking：否；不得用于跨公司 App/网站追踪。
- 数据删除：App 内“我的 → 账号与数据”可发起注销，Web 同步提供入口。

提交前应以实际生产采集行为复核此基线；配置了新的 SDK 或遥测后必须重新检查。
