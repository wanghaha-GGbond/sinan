# 公司论坛：小范围体验准备

本轮新增搜索和发帖入口修复尚未发布；基础文字论坛已在正式站开放。不要把草稿中的计划当作已上线能力。

## 功能范围

- 全部公司动态与各家公司论坛使用同一套帖子、评论、关注与审核规则。
- 本轮增加标题/正文搜索，查询只覆盖可见帖子；支持全局、公司、关注、我的发布范围。
- 搜索显式提交，不逐字请求；分页绑定关键词，百分号等字符按字面搜索，不成为扩大结果的通配符。
- 公司切换保留关键词；清除筛选保留当前动态范围和排序；空列表可以展开并聚焦真实发帖表单。
- 未增加嵌套回复、实时聊天室、图片上传、消息通知或自动推广。

## 体验验收

1. 游客打开总论坛和任一公司论坛，登录后返回原入口。
2. 不同公司投稿彼此隔离；总论坛能汇总审核后的公开帖子。
3. 发帖、回复、关注和取消关注均真实保存，失败不显示成功；投稿未通过审核不公开。
4. 搜索不泄露待审、隐藏、已屏蔽作者内容；切换公司/关注范围后沿用对应权限。
5. 发布前让现有管理员确认能打开审核队列，有人处理投稿和举报。
6. 先邀请少量熟悉的体验者，收集注册、找公司、发帖、评论、手机操作的反馈；不伪造用户、公司讨论或互动数。
