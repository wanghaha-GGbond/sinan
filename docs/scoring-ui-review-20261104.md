## 评分契约

- 方向分：0–10，由用户独立选择，不以未回答维度补默认值。
- 七维：薪酬回报、成长空间、工作生活平衡、管理清晰度、团队协作、工作稳定性、承诺兑现。0 是真实低分；缺失为 null，不参与均值。每维显示其自己的回答数。
- 旧五分制 ratingDimensions 仍兼容，保留在补充分项，不转换为七维、不混合均分。
- C-BTI 是公开问卷的规则推导，不是医学或人格测量，也不是经过校准的 AI 置信概率。API confidence 保持兼容但只是样本强度启发值。
- 五份是“每轴回答数”门槛，不承诺五名独立用户的隐私保证；反刷、独立作者去重和时间衰减需后续独立算法评审。
- 只使用 visible/limited_visible 且未删除评价。待审核/隐藏/删除数据不进入公开汇总。
- 新增 dimensionSummary 为可选加法字段，现有 API 路径与 iOS 旧字段保持兼容；不新增迁移、不执行 seed、不写正式用户数据。

## 正式站事实与验证边界

2026-11-04 只读检查：公司目录 20 家、拥有公开评价的公司 0 家、C-BTI 0 家。不能为填满页面恢复旧 demo 分数。

使用 web-perf 流程核对源代码、网络请求、导航和布局。当前无 DevTools 性能 trace 工具；单次公网页面加载耗时不是稳定 Core Web Vitals，不据此声称性能提升比例。自动化验证问卷多次进出只产生一次 document 请求、搜索防抖和已有跨页面目录缓存仍有效。

发布前仍需要：GitHub Web/iOS/Cloudflare CI、隔离 PostgreSQL 测试、受保护 staging 核心 E2E、正式部署后只读验收。公司新增 API 的用户归属/限流与聚合 SQL 需真实隔离数据库验收；本地 Docker 守护进程未运行。

本地已通过：111 项单测、76 项页面回归、TypeScript、Next.js 生产构建；lint 0 errors，2 条既有个人页导航 warnings。浏览器验收包含深色手机完整打分/问卷/失败重试、草稿恢复/账号隔离、显式身份选择、原有注册及朋友 UI。测试使用本地夹具，不代表真实线上写入验收。

本轮不宣称全站已达到生产级：PR25 Pulse、Figma、5 家 Logo、公司申报历史页、长期反刷与评分可信度、真实用户可用性测试仍需继续。
